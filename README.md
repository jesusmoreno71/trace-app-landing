# Trace App — Startup Landing Page

A modern, responsive landing page concept created for **Trace**, a fictional productivity application designed to streamline daily tasks and simplify personal workflows. Built with **HTML5**, **Modular CSS**, **Vanilla JavaScript (ES6 Modules)**, and bundled with **Vite**.

## 🚀 Live Demo

Explore the live project here: [https://jesusmoreno71.github.io/trace-app-landing/](https://jesusmoreno71.github.io/trace-app-landing/)

## ✨ Key Features

- **Hero Section & Video Modal:** Impactful entry layout integrated with interactive video showcase triggers (`video.js`).
- **Feature Showcase & Interactive Slideshow:** Multi-section display driven by custom carousel functionality (`slideShow.js`, `caracteristicas.js`).
- **Pricing Plans:** Transparent pricing card layout structured for multi-tier subscriptions.
- **Modular Architecture:** Fully decoupled CSS structure (normalize, variables, header, hero, features, pricing, footer) and JavaScript modules imported centrally via `main.js`.
- **Responsive Navigation & Footer:** Semantic layout optimized across mobile, tablet, and desktop viewports.

## 🛠️ Tech Stack

- **Markup:** HTML5 (Semantic Structure)
- **Styling:** CSS3 (Modular Stylesheets, Custom Properties & Google Fonts: *Nunito Sans*)
- **Scripting:** Vanilla JavaScript ES6+ (Modular File Imports)
- **Build Tool / Bundler:** Vite
- **Deployment:** GitHub Pages (via GitHub Actions)

## ⚙️ Development & Local Setup

To run this project locally:

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/jesusmoreno71/trace-app-landing.git](https://github.com/jesusmoreno71/trace-app-landing.git)
   ```

2. **Install dependencies:**
   npm install

3. **Start the development server:**
   npm run dev

4. **Build for production:**
   npm run build


## 📌 Project Purpose
Developed to practice modular CSS organization, JavaScript module separation (import/export), dynamic DOM interactions (slideshows/modals), and production builds within a Vite environment.
